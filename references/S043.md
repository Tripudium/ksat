## Application and trusted components

E002 builds this C checker locally and on Blythe with `cc -std=c99 -O2`.
UNSAT classification requires exit 0 and an explicit `s VERIFIED` verdict;
exit 0 alone is insufficient because some error branches return zero.
The negative-control preflight requires a completed explicit `s NOT VERIFIED`
verdict with exit 1. Tests verified Glucose42 DRAT output on small proper CNFs
and rejected an invalid certificate. Inputs, proofs, logs and binary hashes
are retained. The checker is a trusted software component, not a formally
verified checker or proof of a random-SAT theorem.

The upstream trivial-UNSAT parsing branch may print VERIFIED with exit 1;
our conservative acceptance rule would leave that case unresolved. Generated
proper k>=2 formulas have no initial unit or empty clauses, so this is outside
the intended input path. The vendored source was not changed to mask it.
